Sing-box 跨平台通用代理内核从入门到专家级配置

2026-11-13 更新 纯正开源协议先锋 模块化 JSON 路由引擎

在当今代理工具领域，由 SagerNet 核心开发团队操刀的 Sing-box 正以惊人的迭代速度重塑整个生态。它不仅是一个跨平台的网络框架，更是目前对新一代 UDP 协议（Hysteria 2、TUIC v5）以及现代 TLS 伪装协议（VLESS Reality、ShadowTLS）支持最纯正、性能最极致的底层核心。

为什么技术极客都在转向 Sing-box？

1. 全平台统一内核：无论是 Android、iOS、macOS、Windows 还是 Linux 嵌入式路由器，底层均运行相同的 Go 语言核心代码，规则语法高度一致。
2. 极低的内存与 CPU 消耗：重写了整个网络栈，内存常驻开销远低于传统 Java/Electron 方案，在低配服务器与移动端续航表现极其亮眼。
3. 现代化 JSON / SRS 规则编译：摒弃冗长容易出错的 YAML 缩进，支持编译为二进制 .srs 规则集，千万条规则检索也能在毫秒内完成。

一、Sing-box 诞生背景与架构革新

过去代理工具碎片化严重：V2Ray 核心配置臃肿复杂、Xray 针对特定协议不断修补、传统 Clash 对新协议响应缓慢。Sing-box 在设计之初就立足于“模块化”理念，将入站 (Inbounds)、出站 (Outbounds)、路由 (Route)、实验性功能 (Experimental) 与独立 DNS 系统严格解耦，构建了前所未有的纯净网络管线。

三、JSON 核心配置文件结构解析

Sing-box 采用标准的 JSON 格式组织网络拓扑。一个典型的现代化配置文件包含以下五个核心模块： 

{
  "log": { "level": "info", "timestamp": true },
  "dns": {
    "servers": [
      { "tag": "dns-remote", "address": "https://1.1.1.1/dns-query", "detour": "select" },
      { "tag": "dns-direct", "address": "223.5.5.5", "detour": "direct" }
    ],
    "rules": [
      { "outbound": "any", "server": "dns-direct" },
      { "geosite": "cn", "server": "dns-direct" }
    ]
  },
  "inbounds": [
    { "type": "tun", "tag": "tun-in", "interface_name": "tun0", "inet4_address": "172.19.0.1/30", "auto_route": true, "strict_route": true }
  ],
  "outbounds": [
    { "type": "selector", "tag": "select", "outbounds": ["node-hk", "node-jp", "direct"] },
    { "type": "direct", "tag": "direct" },
    { "type": "block", "tag": "block" }
  ],
  "route": {
    "rules": [
      { "geosite": "category-ads-all", "outbound": "block" },
      { "geosite": "cn", "outbound": "direct" },
      { "geoip": "cn", "outbound": "direct" }
    ],
    "auto_detect_interface": true
  }
}

四、Hysteria 2 与 TUIC 协议优势

在晚高峰跨洋骨干网严重拥堵、TCP 丢包率飙升的极端网络环境下，传统 TCP 代理协议往往出现严重的队头阻塞，带宽断崖式下滑。

  • Hysteria 2：基于标准 QUIC 协议并重新定制了极其强悍的 Brutal 拥塞控制算法。即便在 20%～40% 恶劣丢包率下，依然能强行跑满本地物理带宽，是 4K/8K 视频与海外直播的“起死回生”神器。
  • TUIC v5：专为高并发短连接量身优化的 QUIC 协议，极大幅度缩短 TLS 握手 RTT 轮次，网页点开秒加载。

Sing-box 是首个将这两个协议作为“一等公民”深度整合进主线架构的工具，兼容性与性能远超其它包装层。

五、高性能 TUN 网卡模式实战

在 Sing-box 中，启用 TUN 网卡只需在配置的 inbounds 中引入 type: "tun"。它支持：

  • auto_route: true：客户端启动时自动修改主机默认网关路由表，退出时自动复原，彻底防止断网。
  • strict_route: true：开启严格路由模式，防止 DNS 泄漏或特定流量从旧的物理网卡边缘旁路溢出。
  • endpoint_independent_mapping (Full Cone NAT)：支持完整 Full Cone NAT 映射，对 Nintendo Switch、Steam 联机对战以及 P2P 下载极其友好。

六、独立 DNS 路由引擎与防泄漏

传统代理软件常常因为操作系统本地 DNS 缓存而导致“访问国内网站走海外”、“访问海外服务被运营商污染”。Sing-box 的内部 DNS 引擎具备独立的入站与出站路由：

  1. 当发起网络访问时，Sing-box 先通过 GeoSite 规则匹配。
  2. 属于中国大陆的域名，直接经由阿里 DNS (223.5.5.5) 或腾讯 DNSPod 解析，获得国内 CDN 最佳就近节点。
  3. 海外受限域名，完全封包经由加密代理通道送往 Cloudflare / Google DoH 境外远端解析，彻底杜绝任何形式的 DNS 污染与泄露。

七、启动失败与连接报错速查

错误日志提示 故障诱因 排查与修复步骤

八、常见问题解答 (FAQ)

Q: Sing-box 是否兼容 Clash 的 YAML 格式配置文件？

Sing-box 核心仅直接读取 JSON 格式配置。不过目前主流机场通常已提供原生的 sing-box 订阅链接。若机场未提供，可通过业界成熟的 Subconverter 订阅转换工具 一键转为 Sing-box 格式。

Q: 为什么导入订阅后开启代理提示“缺少必要的内核权限”？

Sing-box 开启 TUN 虚拟网卡模式时，在 Windows 上需要管理员权限，在 Android 或 iOS 上需要允许添加 VPN 配置。如果在桌面端使用图形客户端，请在设置中安装 Service 辅助提权服务。

Q: Sing-box 的主要优势是什么？适合哪些人群？

Sing-box 核心优势在于极低内存占用（通常仅几十 MB）、更低 CPU 唤醒频率以及对现代前沿协议（如 Hysteria 2、TUIC v5、ShadowTLS）的原生支持。非常适合追求轻量化系统常驻与高吞吐的进阶玩家。
