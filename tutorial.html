主流代理客户端下载与配置教程

无论你是 Windows、macOS 办公，还是 iPhone、Android 移动端追剧，这里为你整理了当前主流安全客户端的官方开源下载渠道与零门槛订阅配置步骤。

Clash Verge Rev
Windows / macOS / Linux · 桌面首选

基于 Clash.Meta (Mihomo) 内核的现代化客户端。界面优雅、中文支持友好，内置智能规则分流与 TUN 虚拟网卡模式。

  • 1在官网或 GitHub Releases 下载安装包
  • 2在“订阅”界面粘贴机场提供的 Clash 订阅链接
  • 3右键选中配置并开启“系统代理”即可顺畅翻越
查看详细图文教程 GitHub 官方下载
Shadowrocket (小火箭)
iOS (苹果手机 / iPad) · 必备神器

iOS 平台最经典的代理工具，支持扫码导入订阅、规则分流、节点测速与场景模式。需使用外区 Apple ID 在 App Store 购买下载。

  • 1登录美区/港区 Apple ID 在 App Store 安装
  • 2打开小火箭，点击右上角【+】扫描或粘贴节点订阅
  • 3选择延迟最低节点，轻触顶端开关连接
查看详细图文教程 App Store 详情
Sing-box
全平台通用 · 新一代通用代理内核

由官方团队打造的新一代通用网络框架。极低内存与 CPU 占用，原生支持 Hysteria 2、TUIC、Vless、Shadowsocks 几乎全协议。

  • 1前往 Sing-box 官方跨平台客户端下载
  • 2导入服务商提供的 Sing-box 格式配置链接
  • 3启用并开启“TUN 模式”实现全局智能代理
查看详细图文教程 Sing-box 官网
Surge
macOS / iOS · 顶级高级网络开发神器

苹果生态下的天花板级网络工具。具备无可挑剔的抓包调试、全自动智能策略组、零延迟切换与极高品质稳定性。

  • 1在官网或 Mac/iOS App Store 下载 Surge
  • 2通过机场面板一键托管导入 Surge 托管配置
  • 3享受苹果生态丝滑无感的全自动化跨境网络

V2rayN / V2rayNG
Windows / Android · 经典老牌工具

最广为人知的通用老牌开源客户端，协议兼容度极强，支持 Xray、V2fly、Sing-box 双核心无缝自由切换。

  • 1在 GitHub 下载最新的 v2rayN-With-Core 整合包
  • 2在“订阅分组”中添加机场提供的 V2ray 订阅地址
  • 3更新订阅后在托盘右键设置“自动配置系统代理”

基于 Sing-box / Xray 的强大开源客户端。内置丰富的路由规则、分应用代理功能与一键自签证书支持。

新手配置常见问题排查 (FAQ)

Q1: 为什么导入机场订阅时提示“更新失败”或网络超时？

这通常是因为本地直连无法访问机场的订阅下发域名。可以先开启客户端的“节点测试”或先连接一个免配置备用节点，或者将订阅链接中的域名转为防污染备用镜像再重新拉取。

Q2: 连上节点后，为什么国内微信、淘宝打不开？

说明您的客户端开启了“全局代理 (Global)”模式。请将路由模式切换为“规则分流 (Rule)”模式，客户端就会自动实现国内直连、海外翻越，互不冲突。

Q3: 什么是 TUN 模式？为什么有些软件必须开它？

普通系统代理仅拦截浏览器等遵循系统 HTTP 代理的流量，而终端命令行 (Git/SSH)、微软应用商店、海外游戏等不会走普通代理。开启 TUN 虚拟网卡模式后，系统全盘所有应用网络流量都将被强行接管加速。

Q4: 手机端小火箭 (Shadowrocket) 无法下载怎么办？

中国大陆区 App Store 不提供此类应用。您可以在苹果手机上登出当前 Apple ID，登录一个美区/港区的 Apple ID，即可搜索购买下载。
